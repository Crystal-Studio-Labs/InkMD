## 🌟 Overview

**InkMD** is a state-of-the-art Markdown editor running entirely in your browser. It combines the simplicity of a notepad with the power of a modern IDE. Whether you are documenting code, writing a blog post, or taking rapid notes, InkMD offers a sophisticated split-pane interface that renders your markdown in real-time.

Unlike traditional editors that require sign-ups or cloud storage, InkMD operates with a **local-first philosophy**. Your keystrokes never leave your browser unless you choose to share them. It is the perfect tool for developers, technical writers, and students who value speed, privacy, and aesthetics.

> "The private, fast, and beautiful way to write markdown on the web."

## ✨ Features & Capabilities

InkMD is engineered to be the last markdown editor you'll ever need.

<div align="center">

| **✍️ Editor Core** | **👀 Live Preview** | **📦 Export & Data** |
| :--- | :--- | :--- |
| 🔹 **Split-Pane View**<br/>Write and preview simultaneously in sync. | 🔹 **GFM Support**<br/>Tables, Task Lists, Strikethrough, and Auto-linking. | 🔹 **Instant Export**<br/>Download your work as `.md` files in one click. |
| 🔹 **Syntax Highlighting**<br/>Auto-detection code blocks via `rehype-highlight`. | 🔹 **Math Support**<br/>(Coming Soon) $LaTeX$ rendering for equations. | 🔹 **Copy to Clipboard**<br/>Formatted HTML or Raw Markdown copying. |
| 🔹 **History Stack**<br/>Robust Undo/Redo Engine (up to 50 states). | 🔹 **Safe HTML**<br/>Sanitized output to prevent XSS attacks while rendering. | 🔹 **Local Storage**<br/>(Coming Soon) Browser persistence so you never lose data. |

</div>

### 🎨 Visual & UI Features
- **Distraction-Free Mode:** The toolbar and unnecessary elements fade away when typing.
- **Responsive Toolbar:** Quick access to Bold, Italic, Lists, Code, Links, and Quotes.
- **Auto-Closing Tags:** Smart handling of brackets `[]` and parentheses `()`.
